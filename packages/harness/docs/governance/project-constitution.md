# Project Constitution

Permanent principles for this project.

## Product Principles

- Keep MVP small.
- Protect the primary user workflow.
- Avoid speculative features.
- Separate MVP, V1, later, and never.

## Engineering Principles

- Tests are required for behavior changes.
- Architecture changes require ADRs.
- Specs drive implementation.
- Missions bound agent sessions.
- Production changes require rollback plans.

## Agent Principles

- One mission per session.
- Observe before edit.
- Stop on uncertainty.
- Do not broaden scope.
- Mark assumptions.
- Preserve durable memory in session notes.
