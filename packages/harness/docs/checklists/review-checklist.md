# Review Checklist

## Scope

- [ ] matches mission
- [ ] no unrelated files changed
- [ ] no surprise API changes

## Correctness

- [ ] acceptance criteria met
- [ ] edge cases handled
- [ ] error states handled

## Tests

- [ ] tests added/updated
- [ ] tests meaningful
- [ ] no tests weakened

## Security

- [ ] auth considered
- [ ] authorization considered
- [ ] input validation considered
- [ ] no secrets/PII leakage

## Maintainability

- [ ] simple code
- [ ] clear names
- [ ] no unnecessary abstraction
- [ ] rollback considered
