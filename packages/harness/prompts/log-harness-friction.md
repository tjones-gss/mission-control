# Prompt: Log Harness Friction

Use this after a mission if the harness felt too heavy, too weak, confusing, or incomplete.

Read:
- .harness/friction-log.yml
- .harness/learning-policy.yml
- runs/templates/post-mission-feedback-template.md

Add one friction event to:
- .harness/friction-log.yml

Include:
- date
- mission
- type
- severity
- description
- evidence
- suggested fix
- status: open

Do not change policies.
Do not change application code.
